⚙️ Engineering & Architecture
Area	Why It Matters
🧱 Modular Parser System	Treat each log type (syslog, nginx, Wazuh, etc.) as a plugin – makes future extension easy
📄 Multi-format Support	Accept .log, .json, .gz, .bz2 – very common in real environments
🧵 Threading for Big Logs	Don’t freeze UI during parsing – use GLib.idle_add or asyncio
💾 In-memory vs Indexed Search	Support both small logs (in-memory) and huge logs (index to SQLite/temp DB)
🔐 User Permission Awareness	If run as regular user, warn if trying to access /var/log/auth.log (which needs sudo)
